10.006-6 Tens-Carry Slider, Quotient Side — dimensional audit and 3× reference

Scope and source status

  • Part: 10.006, Zehnerschieber, Quotientenseite (tens-carry slider, quotient side), drawing revision 10.006-6, current; it supersedes 10.006-3. Identity verified against Drawing-Index.md: page 11 is 10.006-6, and the sheet's own title block agrees. Scale 10:1; the sheet is stamped Abmasse in μ = 1/1000 mm.
  • Primary source: original Contina engineering drawing, drawing-set PDF page 11 / drawing-viewer page 11, rasterized at 300–400 dpi.
  • Parent(s) and quantity: 10.234 Base assembly, stage III; 5 per machine; Stück 5.
  • Material: Stainless hardenable strip steel 0.5 ±10 µm, hard-rolled, Brinell 230–240. General tolerance: ±50 µm, ±30′. Runout: none (dashes). Drawn: 25.8.1950. Revisions: index 3→4 (change 160, 25.8.50), 4→5 (133, 20.10.50), 5→6 (322, 21.11.50).
  • Drawing values: Confirmed where legible; unreadable or unlabeled features are Unverified. ISO limits: Derived (ISO 286-1/-2), where a code is printed. 3× values: Derived project references, not factory specifications.
  • Related: 10006-English-Annotation.md.

Official standards references: ISO 286-1 and ISO 286-2.

No ISO fit code is printed on this sheet, and none is assigned: the limits are explicit ± or +/− micron values.

Relation to 10.005

The two sheets are the same slider apart from the blank: 10.006 has an extra left tab (4 ±100 µm), a 0.1 +40/0 window offset, a toleranced 19.2 ±100 overall length where 10.005 gives 19.7 theoretical, and a 1 0/−50 head step where 10.005 gives 0/−30. The formed side view is identical. Both carry the same material and the same burr-free notch pair; see Part-Dimensions-10005.md for the OBS-007 relationship.
