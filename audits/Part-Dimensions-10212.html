10.212-3 Complete Setting Axle — assembly dimensional audit and 3× reference

Scope and source status

  • Assembly: 10.212, Kompl. Einstellachse (complete setting axle), current drawing 10.212-3, replacing 10.212-1 in the title block. The revision table records “Index 2 in 3 geändert,” change 181 dated 4.5.1950. Drawing-Index.md identifies drawing-set/catalog page 216 as current. Main scale 5:1; pictogram 1:1; stamped Abmasse in μ = 1/1000 mm. Read at 400 dpi.
  • Parent and quantity: 10.240 complete setting knob; eight 10.212 assemblies per machine (title block and 10.210 sheet 10, p212). Its two child sheets each state eight per machine with Kompl. Nr. 10.212. The parent 10.240 also totals eight per machine, so one setting axle per parent assembly.
  • Evidence labels: direct drawing facts Confirmed; calculated values Derived; ambiguous endpoints or units Unverified. 3× values are project references, not factory specifications.

The assembly sheet has no ISO fit code. ISO 286-1 defines the fit system and ISO 286-2 tabulates deviations. The child axle's h6 designation below is inherited from 10.061-5, not a direct 10.212-3 callout.

At Ø2.5 mm the ISO 286 basic-size step is over 1 through 3 mm. For the 10.061 shaft's h6, es = 0, current ISO IT6 = 6 µm and ei = −6 µm, giving Ø2.494–2.500 mm (Derived); the source sheet's older fit table gives Ø2.493–2.500 mm (Confirmed). The 10.029 bore has explicit deviations, not an ISO letter fit. Against the factory sheet's axle limits, the bore/shaft pair yields 2–23 µm diametral interference (2.493 − 2.491 to 2.500 − 2.477), Derived. Using current ISO h6 limits instead gives 3–23 µm. This supports a fixed roller on the turning axle; the assembly itself states no pressing force or finished bore measurement.

The 10.061 child drawing divides its 35.2 ±0.020 mm reference-length band into Pos. 1: 35.18–35.20 mm and Pos. 2: 35.20–35.22 mm (Confirmed from p81). 10.212-3 says the axle is sorted by these positions but does not assign a measured position to a particular roller. The nominal subtraction 9.7 − 5.0 = 4.7 mm could describe the shoulder-to-top-roller offset if the illustrated extension-line reading is correct (Derived, conditional). With the printed 9.7 ±0.050 and child 5.0 ±0.200 limits, the arithmetic range would be 4.45–4.95 mm; this is not a separately controlled factory dimension.
