10.021-4 Number-Roll Pin — dimensional audit and 3× reference

Scope and source status

  • Part: 10.021, Zahlenrollenstift (number-roll pin), drawing revision 10.021-4, current; it supersedes 10.021-2. Identity verified against Drawing-Index.md: page 33 is 10.021-4, and the sheet's own title block agrees. Scale 10:1; the sheet is stamped Abmasse in μ = 1/1000 mm.
  • Primary source: original Contina engineering drawing, drawing-set PDF page 33 / drawing-viewer page 33, rasterized at 300–400 dpi.
  • Parent(s) and quantity: 10.203 / 10.205; 15 per machine (4 in 10.203, 11 in 10.205); Stück 15.
  • Material: Stainless spring-steel wire, Sandvik 2R2, Ø0.8 h8. General tolerance: ±50 µm. Runout: 20 µm marked and side. Drawn: 18.10.49. Revisions: index 3→4 (change 163, 1.5.1950).
  • Drawing values: Confirmed where legible; unreadable or unlabeled features are Unverified. ISO limits: Derived (ISO 286-1/-2), where a code is printed. 3× values: Derived project references, not factory specifications.
  • Related: 10021-English-Annotation.md.

Official standards references: ISO 286-1 and ISO 286-2.

Project 3× reference

Convention used here: the project's tolerance strategy (a project decision) ties tolerance to the manufacturing process, not to the 3× factor. The "simply scaled" values are a comparison only and are not adopted, general tolerances are not silently carried over, and a 3× table is not a factory specification.
