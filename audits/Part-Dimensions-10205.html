10.205-1 Complete Number Roll II — assembly dimensional audit and 3× reference

Scope and source status

  • Assembly: 10.205, Kompl. Zahlenrolle II (complete number roll II), drawing revision 10.205-1, current. Identity verified against Drawing-Index.md: page 196 is 10.205‑1 Kompl. Zahlenrolle II, and the sheet's own title block agrees.
  • Primary source: original Contina engineering drawing, drawing-set PDF page 196 / drawing-viewer page 196, rasterized at 400 dpi, with a contrast-enhanced crop of the pencil marks. Dimensions are in µm unless stated (Abmasse in μ = 1/1000 mm); the sheet scale is 10:1.
  • Child sources: 10.045-6 Number roll II (page 63, audit) and 10.021-4 Zahlenrollenstift, the number-roll pin (page 33, audited in Part-Dimensions-10203.md).
  • Labels: each value is one of direct assembly callout (printed on 10.205-1), inherited component dimension (printed on a child sheet), or calculated / inferred stack-up. Facts are Confirmed, recalculated values Derived, unresolved readings Unverified, judgement calls Inferred.
  • ISO limits: Derived from ISO 286-1 (system) and ISO 286-2 (tables).

Official standards references: ISO 286-1 and ISO 286-2.

This sheet is a near copy of 10.203-1: the same pin, the same two dimensional callouts, the same blank fields, drawn on the same day by the same hand. Only the roll differs. To avoid drifting copies, the pin's own audit lives in the 10.203 file and is summarized here.

ISO 286 fit cases

Both fall in the first ISO 286 size step, "up to 3 mm"; neither nominal sits on a step boundary.

Feature Nominal Code Calculation Resulting limits Source
Pin (shaft) Ø0.800 mm h8 IT8 = 14 µm; es = 0, ei = −14 µm Ø0.7860–0.8000 mm 10.021-4
Pin bore (hole) Ø0.800 mm P7 IT7 = 10 µm; ES = −6, EI = −16 µm Ø0.7840–0.7940 mm 10.045-6

For h, es = 0 and the zone lies below nominal; for P (a hole), ES < 0 and the zone also lies below nominal.

The assembly sheet specifies no fit. Pairing the two component zones is a Derived combination of two Confirmed callouts, not a fit printed anywhere. It gives maximum clearance 0.7940 − 0.7860 = +8 µm and maximum interference 0.8000 − 0.7840 = 16 µm: a transition fit, so an individual pin can seat loosely or tightly. Using the sheet's own hole reading (−7/−16) the maximum clearance becomes +7 µm (Unverified).

Project 3× reference

Convention used here: the project's tolerance strategy (a project decision) ties tolerance to the manufacturing process, not to the 3× factor. The "simply scaled tolerance" column is a comparison only and is not adopted for any process. A 3× table is not a factory specification. Where a callout carries an ISO fit code, the code is re-applied at the scaled basic size and the limits recalculated, matching the 10.203 audit.

Both scaled diameters stay in the same ISO size step as the originals, so the derived transition band (+8 µm clearance to 16 µm interference) is unchanged at 3×. A printed FDM roll cannot hold it; per the project's tolerance decision printed prototype fits come from measurement.
