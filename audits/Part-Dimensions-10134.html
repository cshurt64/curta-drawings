ISO 286 fit cases

ISO 286-1 defines the system; ISO 286-2 tabulates the deviations for letters this project has checked before.

Feature Case IT / fundamental deviation ISO limits Sheet fit table Status
Shaft Ø2 r7 (over 1–3 mm) IT7 = 10 µm (from the tabulated 1–3 mm step) not computed +27/+12 → 2.012–2.027 mm (15 µm span) Confirmed sheet reading; ISO comparison left Unverified

Unlike the e, f, h, p letters checked elsewhere in this project (against fundamental deviations already cross-checked from a reliable table), this project has not independently verified the ISO 286-2 fundamental deviation for r at small diameters. The sheet's 15 µm span does not match the 10 µm IT7 width at 1–3 mm, which would normally flag a disagreement — but without a verified r deviation to compare against, asserting a specific ISO figure here risks repeating the "ISO trap" (using a half-remembered deviation) this project has been burned by before. Flagging as Unverified rather than guessing.
