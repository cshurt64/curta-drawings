10.043-6 Number Roll I — dimensional audit and 3× reference

Scope and source status

  • Part: 10.043, Zahlenrolle I (number roll I), drawing revision 10.043-6, current; it supersedes 10.043-5 (PDF page 59). Identity verified against Drawing-Index.md: page 60 is 10.043‑6 Zahlenrolle I, and the sheet's own title block agrees.
  • Primary source: original Contina engineering drawing, drawing-set PDF page 60 / drawing-viewer page 60, rasterized at 300 and 500 dpi. All dimensions are in µm unless stated (Abmasse in μ = 1/1000 mm); the sheet scale is 10:1.
  • Drawing values: Confirmed where legible on the current sheet. Handwritten values that are hard to read, and features whose meaning the sheet does not state, are labeled Unverified.
  • ISO limits: Derived by recalculation from ISO 286-1 (system of limits and fits) and ISO 286-2 (tabulated IT grades and fundamental deviations), not copied from the sheet's fit table.
  • 3× values: Derived project references, not factory specifications.
  • Related guide: 10043-English-Annotation.md.

Official standards references: ISO 286-1 and ISO 286-2.

ISO 286 fit cases

Two callouts carry ISO fit codes. Both fall in the first ISO 286 size step, "up to 3 mm" (which also covers sizes over 1 through 3 mm).

Feature Nominal Code Basic-size step Calculation Resulting limits Drawing's own fit-table entry Status
Pin bore (hole) Ø0.800 mm P7 up to 3 mm IT7 = 10 µm; ES = −6 µm, EI = ES − IT = −16 µm Ø0.7840–0.7940 mm 0,8-P7, −7/−16 µm → Ø0.7840–0.7930 mm Confirmed callout; Derived ISO limits; fit-table reading Unverified
Bore (hole) Ø2.000 mm F8 (marked *) up to 3 mm IT8 = 14 µm; EI = +6 µm, ES = EI + IT = +20 µm Ø2.0060–2.0200 mm 2-F8, +21/+7 µm → Ø2.0070–2.0210 mm Confirmed callout; Derived ISO limits; fit-table reading Unverified

Both are holes, so the capital letters are correct: for F the fundamental deviation is the lower one (EI > 0, zone above nominal); for P it is the upper one (ES < 0, zone below nominal). Neither nominal sits on a size-step boundary.

The sheet's fit table and ISO 286-2 disagree by 1 µm. The P7 upper limit reads −7 µm (ISO: −6) and the F8 zone reads +21/+7 µm (ISO: +20/+6). The handwriting is small, so this is either a misreading or the older ISA table values in use in 1950. Unverified; the ISO figures are used above as the recalculated reference, and neither is a shop specification.

The 0.15 mm wall between the pin bore and the disc outer surface is the thinnest feature on the part at factory scale. It matters for the replica: a plain 3× scale gives 0.45 mm, roughly one FDM perimeter, so the printed pin bore may break out or split; this needs checking on a test print before any design decision.

Project 3× reference

The factory tolerance, the mathematically scaled nominal, a simply scaled tolerance, and a newly calculated ISO tolerance at the scaled size are four different quantities. The columns keep them separate.

Convention used here: the project's tolerance strategy (a project decision) ties tolerance to the manufacturing process, not to the 3× factor. So the "simply scaled" column is a comparison only and is not adopted for any process, and no fit is inherited from the factory table. Where a callout carries an ISO fit code, the code is re-applied at the scaled basic size and the limits recalculated. This matches the existing 10.041 audit; the 10.038 audit instead shows a geometric-scaling column as a comparison.

The 3× bore of Ø6.000 mm sits exactly on the upper boundary of the "over 3 through 6 mm" ISO size step, so it belongs to that step (IT8 = 18 µm). A 6.001 mm bore would fall in the next step (IT8 = 22 µm). The 3× pin bore stays in the first step, so its P7 limits do not change from the factory size.

None of this is a fabrication tolerance. A printed FDM roll cannot hold these limits; per the project's tolerance decision the printed prototype targets are set from measured fits, and a machined roll would hold near the factory absolute band, not the 3× band.

Assembly relevance

The title block names 10.203 (Complete number roll I) as the only parent, and the 10.203-1 sheet (page 193) shows the roll paired with one 10.021 number-roll pin. These are inherited component dimensions, not direct assembly callouts.

  • Pin interface: the Ø0.8 P7 bore receives the 10.021 pin (Ø0.8 h8 on 10.021-4). The assembly sheet prints no fit; pairing the two component zones gives a Derived transition, up to +8 µm clearance to 16 µm interference — see Part-Dimensions-10203.md. 10.203-1 also limits the digit face's rotation to ±8° (assembly-level control, Confirmed on p193).
  • Axle interface: the Ø2 F8 bore presumably rides on a Ø2 axle, plausibly the 10.008 counter-wheel axle. That axle's own sheet (10.008-4, page 14) reads Ø2 h6, and Machine-Facts §4's h7 is corrected. No drawing states the pairing (Inferred); if they mate, the Derived fit is a clearance fit of +6 to +26 µm — see Part-Dimensions-10243.md.
  • Quantity: 4 per machine, one per 10.203 assembly.
