  • Labels: printed content Confirmed; calculated values Derived; unresolved readings Unverified. 3× values are geometric references, not factory specifications.

3× reference

No ISO fit is recalculated. A formed spring strip is not a pure geometric scaling problem.

Derived. A 3× table is not a factory specification. This is a formed leaf spring: tripling every length in the same 0.3 mm-equivalent material multiplies bending stiffness by 3 (stiffness ∝ w·t³/L³, with width and length both ×3 and thickness held at the "same material" assumption) — but a genuinely 3× part (0.9 mm strip) is 27× stiffer at the same thickness ratio unless the strip is re-derived thinner. Which convention applies is a design decision, not carried over from the factory part. See the project's tolerance strategy.
