ISO 286 fit cases

ISO 286-1 defines the system; ISO 286-2 tabulates the deviations. Two cases, both over 1 through 3 mm.

The f8 disagreement (sheet es = −7 vs. ISO's tabulated −6, with the same IT8 = 14 width carried through to ei = −21 vs. ISO's −20) joins the small set of non-h/H fits already flagged elsewhere in this set with a consistent ~1 µm shift from the ISO 286-2 table (F8/N7/R7/R8 fits noted on other sheets) — read as a possible pre-ISO (ISA) tolerance-table artifact of the era, not confirmed by any sheet or reference.

3× reference

The h8 case is recalculated at the tripled basic size (1.7 mm × 3 = 5.1 mm is in "over 3 through 6 mm": IT8 = 18 µm). The f8 case is not recalculated: a fundamental deviation is a property of the size step, not something that scales linearly with the part, so no meaningful "3× ISO f8" exists to compute; the sheet's own es/ei values are not scaled either.
