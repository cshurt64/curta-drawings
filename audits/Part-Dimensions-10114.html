ISO 286 fit cases

ISO 286-1 defines the system; ISO 286-2 tabulates the deviations. Two cases.

Feature Case IT / fundamental deviation ISO limits Sheet fit table Status
Pivot bore Ø3.3 H8 over 3–6 mm; IT8 = 18 µm; EI = 0 3.300–3.318 mm +18/0 Confirmed; agrees
Roller-pin bore Ø1.7 H8 over 1–3 mm; IT8 = 14 µm; EI = 0 1.700–1.714 mm +14/0 Confirmed; agrees

For H, EI = 0 and the zone is above nominal. Per Machine-Facts.md §720, the pivot bore takes the bushing 10.125's Ø3.3 p9 stem, an ISO transition-to-interference fit (−6 to +42 µm).
