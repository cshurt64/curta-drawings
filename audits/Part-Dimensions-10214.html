Open points

  1. No dimension, no stamp (Confirmed). Recorded so nobody reads a unit into it.
  2. What the cross-hatched band is (Inferred). The grid symbol is usually a knurl or check pattern; 10.062-4 does not name it. It is a different feature from the 120 Teile am Umfang serration, which the sheet shows as a toothed arc.
  3. Which part meets the Ø48.2 H8 bore (Unverified).
  4. The hart difference (Confirmed). This sheet says schwarz eloxiert, the sister sheet 10.202-2 says schwarz eloxiert / hart.
