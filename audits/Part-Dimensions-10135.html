10.135-3 Bearing Pin — key measurements and tolerances

Scope and source status

Identity agrees with Drawing-Index.md and the title block on drawing-set/catalog page 170 (viewer page 170). Scale 10:1 (reference view M1:1); stamped Abmasse in µ = 1/1000 mm.   • Material: So Ms 58 Mn Ø2,5 (special brass, 58% copper alloy with manganese, Ø2.5 mm bar stock) — per the change note, this replaced an earlier bronze, WBz8.
  • General tolerance: ±100 µm linear, ±1° angular. Runout: 20 µm radial on marked surfaces (side runout a dash); unmarked 50 µm radial, side unmarked a dash. Finish: ▽, with ▽▽ in brackets.
  • Labels: printed content Confirmed; calculated values Derived; unresolved readings Unverified. 3× values are geometric references, not factory specifications.

Selective-fit grading

No ISO 286 letter fit is used anywhere on this sheet — see below. Instead one dimension is selectively graded, with a note Aussortieren nach: ("sort by:") linking it to a two-position table:

Pos. Range (mm)
1 von 3.49 – 3.51
2 über 3.51 – 3.53

The graded feature itself is printed on the body as 3.51 ±0.020 mm (3.490–3.530 mm), spanning exactly the combined range of the two sort positions — the same selective-fit convention used on 10.064, 10.077, 10.099 and 10.120.

ISO 286 fit cases

None currently on this sheet. Two dimensions originally carried ISO letter fits — the top pin was Ø0.8 h8 and the base was Ø2.3 j8 — but the change note records both letters being struck and replaced with plain numeric tolerances (0/−18 and ±10 respectively). The printed body of the drawing carries only the numeric values, with no h8/j8 designation remaining, so there is nothing to check against ISO 286-2 on the current issue.
